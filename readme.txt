[▼スケジュール管理アプリの実装内容（5日先まで天気予報付き）]
・Vue(2)でカレンダーを表示する
・予定の追加・完了・削除を実装する
・月切り替えを実装する
・お天気API（OpenMeteo）と連携する
・当日から5日分のお天気アイコンを表示する
・当日から3日目までサンプルタスクを初期表示させる


[▼アピールポイント]
本アプリはただのToDoアプリではなく、外部の天気API（Open-Meteo）から取得した非同期データと、ユーザーが入力したタスクデータをJavaScriptのfindメソッドを用いて日付をキーに動的にマッピング（結合）するロジックを実装しました。これにより、ユーザーが予定を立てる際にその日の天気を一目で確認できる実用性を考慮しました。
