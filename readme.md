◆Schedule Management App

◆概要<br>
Schedule Management App（スケジュール管理アプリ）は、日々の予定やタスクを簡単に登録・管理できるアプリケーションです。シンプルなUIで、予定の追加・完了・削除をスムーズに行うことができ、個人利用を想定した使いやすい設計となっています。<br>

◆主な機能
- 📅 Vueでカレンダーを表示する。
- 📅 当日から3日目までサンプルタスクを初期表示させる。
- ➕ 予定の追加・完了・削除。
- ✏️ お天気API（OpenMeteo）と連携。当日から5日分のお天気アイコンを表示。
- 📆 月切り替えを実装する。
- ⚡ シンプルで軽快な操作性。
<br>

◆本アプリの使い方<br>
【予定を追加】<br>
1、予定を追加したい日を選択します。<br>
2、予定を記入。<br>
3、「予定を追加」ボタンを押します。<br>

【不要になった予定を削除】<br>
1、予定を削除したい日を選択します。<br>
2、削除したい予定の右側にある「削除」ボタンを押します。<br>

【予定を完了】<br>
1、完了した予定のある日を選択します。<br>
2、完了した予定の左側にあるチェックボックスを押します。<br>
3、取り消し線が引かれたら予定完了です。<br><br>


【▼本アプリの開発理由（背景）】<br>
本アプリの開発理由は主に以下2点です。<br>

1、Vue.jsのデータ駆動（リアクティブ）に対する深い理解<br>
スクールのカリキュラムでは、カレンダーのUI構築を主にJavaScript（生JS）による直接的なDOM操作で行っていました。これを「データが変われば画面が変わる」というVue.jsのリアクティブシステム（データ駆動）で再構築することで、状態管理の基礎とVueの真髄を身につけたいと考えたためです。<br>

2、定番だからこその「データ結合」への挑戦<br>
「カレンダー×天気×タスク管理」は定番の題材です。しかし定番だからこそ設計の奥深さがあると考えます。単にAPIの表示だけでなく、「外部から取得した天気データ」と「ユーザの入れたタスクデータ」をJavaScript（find）メソッドを活用して「日付文字列（YYYY-MM-DD）」を共通キーとして動的に結合するロジックに挑戦したかったからです。<br><br>


また、スクールではVue2を学んでいましたが、現在はモダンなフロントエンド開発に対応できるようVue3（Composition API / Script Setup）の学習を個人で進めています。将来的には本アプリをVue3へ移行し、さらに状態管理ライブラリ（Pinia）を用いた柔軟な設計へとアップデートすることを考えています。
