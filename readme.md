◆Schedule Management App

◆概要<br>
Schedule Management App（スケジュール管理アプリ）は、日々の予定やタスクを簡単に登録・管理できるアプリケーションです。シンプルなUIで、予定の追加・完了・削除をスムーズに行うことができ、個人利用を想定した使いやすい設計となっています。<br>

◆主な機能
- 📅 Vueでカレンダーを表示する。
- 📅 当日から3日目までサンプルタスクを初期表示させる。
- ➕ 予定の追加・完了・削除。
- ✏️ お天気API（OpenMeteo）と連携。当日から5日分のお天気アイコンを表示。
- 📆 月切り替えを実装する。
- ⚡ シンプルで軽快な操作性。
<br>

◆本アプリの使い方
【予定を追加】<br>
1、予定を追加したい日を選択する。<br>
2、予定を記入。<br>
3、「予定を追加」ボタンを押す。<br>

【不要になった予定を削除】<br>
1、予定を削除したい日を選択する。<br>
2、削除したい予定の右側にある「削除」ボタンを押す。<br>

【予定を完了】<br>
1、 予定を完了したい日を選択する。<br>
2、完了したい予定の左側にあるチェックボックスを押す。<br>
3、取り消し線が引かれたら予定完了。<br>


【▼アピールポイント】<br>
本アプリはただのToDoアプリではなく、外部の天気API（Open-Meteo）から取得した非同期データと、ユーザーが入力したタスクデータをJavaScriptのfindメソッドを用いて日付をキーに動的にマッピング（結合）するロジックを実装しました。これにより、ユーザーが予定を立てる際にその日の天気を一目で確認できる実用性を考慮しました。
